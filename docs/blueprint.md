# **App Name**: ClickTrack

## Core Features:

- Click Recording: Record user clicks within a time window.
- Timer: Implement a timer to track the duration of the test.
- Score Calculation: Calculate the CPS (clicks per second) score.
- Data Visualization: Visually represent the click rate over time.

## Style Guidelines:

- Primary color: Dark slate blue (#3B5998), a serious and focused tone.
- Background color: Very light gray (#f0f2f5), nearly white for high contrast.
- Accent color: Steel blue (#4682B4) to add clarity to interface elements.
- Font: 'Inter', a grotesque sans-serif font.
- Simple, clean layout with a focus on usability. Prominent start button, clear timer display, and a large area for clicking.
- Minimal set of icons, if any. Focus on simple, easily understandable visuals.
- Subtle visual feedback on clicks. Immediate but not distracting.
